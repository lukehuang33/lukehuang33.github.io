# Luke D. Huang — Personal Website

A static personal website designed for GitHub Pages.

## Local preview

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish

Create a public repository named `lukehuang33.github.io`, add it as the remote,
and push the `main` branch. GitHub Pages will serve the site at
`https://lukehuang33.github.io/`.

The site uses plain HTML, CSS, and JavaScript with no build step.
